# Lehrenden-Dashboard
Ein interaktives Dashboard für Lehrende, das als Block in das Moodle-Dashboard integriert werden kann. Ziel ist es, Lehrende dabei zu unterstützen, die Nutzung und den Lernfortschritt in ihren Moodle-Kursen schnell zu überblicken und daraus Hinweise für die Gestaltung und Weiterentwicklung ihrer Lehrveranstaltungen abzuleiten
